# 退役日产 Leaf 定期容量复验：一次有正面结果的公开回放

**在 41 个原本可选的复验时点，实验事前锁定的规则提前作出 31 次容量判断。后续完整放电证实 5 次放行、26 次判退全部正确。31 个放电工步实占 406.92 通道小时。** 在已经做标准充电的工位，另一条事先为该工步固定的规则覆盖全部 88 次测试，其中 65 次可提前决定，对应 850.98 通道小时。两项属于替代作业方案。

## 应用对象、来源与锁定

Cui 等公开的斯坦福–Relyion 档案含两块退役 Nissan Leaf 原包的 8 个测量单元。作者后续论文明确说明端子接入两只并联软包，每个 2P 单元在文章中称为一个 cell。2.1 号来自二代 Leaf，其余七个来自一代 Leaf。以原论文 32.5 Ah 标称尺度为依据，考察慢速放电在 4.0 到 3.0 V 工作窗内能否交付 22.75 Ah。这是研究指定的工位容量要求，不能外推为全电压范围剩余容量或综合安全等级。后续论文另报 33.1 Ah，本实验按事先引用的原论文尺度执行。日期以作者发布的测试文件为准，从 2022-01-27 至 2023-07-06，共有 88 个有完整参照的实际访问。

本项目此前未用这批数据选规则，两块原包全部进入验证集，未用其中一个包校准另一个包。选取该来源时已看到原论文报告的首访充电值。PROTOCOL.md 于读取后续参照前在本地取哈希，READOUT.md 记录查看文件结构与一个锚定访流程后的工步识别和同访次要比较。两份锁定均无第三方时间戳。实测放电量、电流积分和作者工步统计逐访核对。按实测电流和时间独立积分，88 访与硬件计数器的最大绝对差为 0.00730 Ah。

## 主检验：在下一次复验前决定是否测量

按同一单元的实际访次组成不重叠的奇偶对。每个奇数访用完整参考放电建立锚点；在紧随的偶数访开始前，仅用上次实测容量作判断。高于 24.375 Ah 提前放行，低于 21.125 Ah 提前判退，两端和中间转测。这一留白取铭牌的 5%，与错误概率预算各 5% 是两个不同的量。实际有 47 个奇数访（含末尾未配对访）、41 个偶数访。没有把拟跳过的参考容量用作下一次输入。

| 评价分母 | 合格时能提前判断 | 低于规格时能提前判断 | 误放／误退 | 可提前判断／所有访问 | 对应放电工时 |
|---|---:|---:|---:|---:|---:|
| 事前指定的 41 个可选偶数访 | 5/14（35.71%） | 26/27（96.30%） | 0/27，0/14 | 31/41 | 406.92 小时 |
| 全 88 访，47 个锚定访照常测 | 5/32（15.63%） | 26/56（46.43%） | 0/56，0/32 | 31/88 | 406.92 小时 |

在可选复验分母上，两等级均超过 20% 情景门槛。若采买方规定所有进站访次都要计入，则主规则合格侧的 15.63% 低于门槛。提前决策对应的通道小时占偶数访参考工时的 72.77%，占全部访参考工时的 33.90%。只取每单元首次偶数访时，有 7 个低容量判退正确，唯一合格单元转测。公开档案没有提供全部预约或取消记录，分母是实际记录的访次。

## 同访工位：用已经发生的标准充电决定能否省去随后的放电

源工序先从来样状态放至 3.0 V，再以约 1.55 A 及恒压阶段充到 4.0 V，随后执行 4→3 V 的完整参考放电并重充。第二条规则在已完成第一次标准充电、尚未执行参考放电时取得充入 Ah，规格和阈值与主方案相同。两边使用相同数值尺度。充电对照和参考均来自一次真实工步；项目代码按时间提取。归入工时的只有完整参考放电段，不含前置调 SOC、充电、后续重充或其他诊断。

在同一 41 个偶数访，两条规则的 41 个动作逐一相同。在全部 88 个有完整测量的访问中，同访规则有 10 次提前放行、55 次提前判退、23 次保留完整放电。低容量类 55/56 可判（98.21%），合格类 10/32 可判（31.25%）。两侧均零观察错误。全排程中可提前判断的比例为 65/88（73.86%），这些工步对应 850.98/1,200.39 个放电通道小时（70.89%）。这是解读原始工步后登记的次要比较，全档属描述性回放。不把主项的 31 次与同访的 65 次相加。真实档案里 88 次放电均已执行。省下的净工时、采用该流程对未来状态轨迹的影响均未现场实测。

这里能利用充入量的理由可以直接从档案核查。同访标准充电量与后续参考放电量的绝对差，中位 0.054 Ah，最大 0.334 Ah。两者都低于本规则的 1.625 Ah 留白。事后取消留白、直接比较充入量和 22.75 Ah，在本批 88 访也无观察错误。对上一访容量直接作同样强制判断，则有一次误放，参考值 22.643 Ah。该检查解释留白的作用，不能由目标数据重新确定投入使用的阈值。结果支持简单测量的工程价值，对复杂求解器的额外增益需另立比较。

## 能否推广到新包

两个预算均按真实等级内全部尝试作分母，转测也在分母内。档案里两条冻结规则观察到的误放与误拒均为零。八个 2P 单元的纵向重复不足以建立面向未来来包的双侧 5% 置信保证。尤其在同访全档，一代原包占 22 个合格访（2 次提前放行）和全部 56 个不合格访；二代原包只提供合格访，其中 8/10 次提前放行。一代原包单独的合格侧决断率只有 2/22。首访逐单元单列时，7 个低容量单元被正确判退，唯一合格单元转测。因此最强论断针对这批电芯的**定期复验**。此结果未验证原 CETL-B 森林迁移、首次来料放行率，或任一新包工位的保证。研究中的 20% 是事前指定的作业情景。

## 复算

Python 3.12，numpy 2.3.5，pandas 2.2.3，openpyxl 3.1.5。需要约 50 MB 原始数据。每次工作表包含调 SOC 放电及充电后的规范放电，脚本仅以后一个为参照。根目录有一份 1.3 通道的独立日期文件，根据作者文件中的通道编号归位。check.py 单独读工作簿内部 XML 的 CycleStatistics 数据，与原处理的逐工步电压、电流、容量、时长、分类及计数核对。results/visits.csv 和 results/traces.csv 可按原文件逐条反查。动作封存后再执行 adjudicate。

```bash
sha256sum -c LOCK.sha256
python fetch.py raw/Cby20.zip
python replay.py score raw/Cby20.zip rerun
python replay.py adjudicate raw/Cby20.zip rerun
python check.py raw/Cby20.zip rerun
python compare.py rerun
diff -rq results rerun
```
