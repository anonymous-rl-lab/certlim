# 冻结 CETL 容量筛选规则的公开外部回放

**结论。** 同为额定 15.5 Ah，CETL-B 的冻结规则在 ReLiB-100k 公开档案中将大量容量合格记录判退。对全档案中参考容量可确认的 6,907 条，误退 5,356 条（77.54%），远超 5% 预算。当前证据支持在该数据来源保留完整放电复测。本实验所有输入均来自公开数据。

## 研究问题与结果

判断参考放电容量是否达到 10.85 Ah（15.5 Ah 的 70%，等于门槛计合格）。误放行的分母为不合格记录，误判退的分母为合格记录。允许转复测，两侧错误预算各 5%。使用 ReLiB-100k 完整公开档案中的 15.5 Ah 子目录，按完整文件路径的 SHA-256 先选 1,024 条，先运行冻结规则，再读取参考容量。主样本揭盲后追加了包含主样本的全档案普查。它们来自同一档案。

| 结果 | 事先选定的主样本 | 追加的全档案普查 |
|---|---:|---:|
| 充电记录数 | 1,024 | 6,909 |
| 冻结规则放行 / 判退 / 转复测 | 0 / 791 / 233 | 0 / 5,358 / 1,551 |
| 可确认参考容量 | 1,024 | 6,907 |
| 参考合格 / 不合格 | 1,024 / 0 | 6,907 / 0 |
| 误退合格记录 | 791 / 1,024（77.25%） | 5,356 / 6,907（77.54%） |
| 已记录第 3 工步放电 | 1,024 | 6,909 |
| 在这些记录中跳过整个放电步骤 | 0 | 0 |

其余两份文件在第 3 工步结束，缺少进入下一工步的完成标记。二者末个放电累计容量分别为 15.019 和 15.133 Ah；冻结规则都判退。按照作者生成脚本直接采纳这两个末值，全档案为 5,358/6,909（77.55%）误退。主结果保留较保守的完成核查。即使完全忽略两者，已确认错退数占全部档案仍有 77.52%。这一有限档案反例无需假设不同电芯相互独立。缺少不合格类分母，故无法估计总体条件误放率。文件名六个日期的结果见逐日期表。

**工作量。** 5,358 是策略会提前判退的记录数，其中 5,356 已证实错误。全部文件都有实际放电轨迹。可确认这些记录中跳过整个放电的次数为 0；工作单级别的实际部署收益在此未观测。按拥有完整放电记录的公开档案取样，也无法估计整条产线的免测率。

## 规则冻结、输入与检查

原 CETL 研究包给出生成程序、分割和阈值。本次仅使用原来的 1,110 条训练样本和固定随机种子恢复 200 棵树的节点，将其固化在 forest.npz 中。直接沿用原来 723 条校准样本产生的两个阈值。运行时只读原始顺序的 40 项充电特征，严格大于 0.8875340919192738 放行，严格小于 0.692783304648114 判退，其他情况转复测。无效充电输入按原规则转复测。历史 2,890 条已发表动作及所有 1,400 条历史留出分流完全复现，前者分数和已发表舍入值的最大绝对差约 5.0×10⁻¹³。森林与重建的原 sklearn 实现对这 2,890 个输入给出逐比特一致的结果。

主样本另用 CSV 逐行读取器、工步数字编号和原版 sklearn 森林复核。1,024 个预测动作及参考容量全部一致。再用名义 3 秒间隔积分放电电流，1,024 条在规格门槛两侧的分级也全部一致，积分与计数器差的绝对值中位数为 34.2 mAh。主样本实测范围为 13.677–15.837 Ah。机器 CSV 没有逐点时钟。全部 6,909 条的充电电流和累计电量推得的采样节拍与 3 秒相容，并非逐点时标认证。作者的 512 点压缩版本未用。

**来源差异。** 对每条充电记录先取电流中位数，再在来源内取中位数，CETL 训练集为 10.0 A，ReLiB 主样本为 6.0 A。每条充电记录的采样点数中位数从 1,603 变为 2,561。冻结模型显式使用电流、采样点数和跨越电压阈值的时间。该比较揭示了可测量的输入变化；电芯来源、初始状态和其他工况也可能影响预测，当前比较无法单独估计电流的因果效应。

**可追溯范围。** 15.5 Ah 档案的逐记录字段为电压、电流、累计容量、工步编号和名称，文件名还带时间样式编码。作者发布物没有给出连接这些记录与原电池包、到货批次或取消工单的映射，也未逐条证明 IFR32135 型号。对原 CETL 全部 4,000 条充电曲线以及 ReLiB 自身，未发现精确哈希或约定的近似签名重合。仍缺少可核验的物理序列号，故定位为同额定容量的外部档案回放。六个文件名日期仅作描述性分组。已检索的另一份 LINKE AOC15 原始导出只有电压、容量及工步状态，缺独立电流列；有原包映射的退役笔记本电芯数据则不匹配这里的型号和额定容量。二者均不用于 CETL-B 的主检验。

## 复算

使用 Python 3.12、requirements.txt 中的版本及 zstd 命令。作者的大型原始档案按字节哈希从发布地址下载。下列命令中的 out 目录可自定。score 步骤写出仅依赖充电的逐条动作及哈希，adjudicate 步骤校验哈希后对接放电容量。census-score 使用原样规则覆盖完整档案。

```bash
python -m pip install -r requirements.txt
python fetch_relib.py raw
python replay.py score raw/15.5Ah.tar --out rerun/primary
python replay.py adjudicate raw/15.5Ah.tar --out rerun/primary
python replay.py census-score raw/15.5Ah.tar --out rerun/census
python replay.py adjudicate raw/15.5Ah.tar --out rerun/census
python ../CETL/fetch.py raw/cetl
python check_readings.py raw/cetl/CETL-data.mat ../CETL/results/predictions.csv raw/15.5Ah.tar --out rerun/primary
```

public_results 保存锁定主分析，public_census 保存追加普查。两者都有充电决策、逐条放电核验、按文件名日期的汇总和预算结果。equivalence.json 记录历史动作的等价性检查。PUBLIC_PROTOCOL.md 与 PUBLIC_ADAPTER.md 是本地在主样本揭盲前写入并取哈希的约定；这次执行未在外部注册平台登记。CENSUS_NOTE.md 记录追加分析的时点。若按独立电芯假设计算单侧 97.5% 二项上界，须保留该假设；当前结论依据有限档案实测比例。
