# Validation B: purchase of a charge trace to omit the following reference discharge

This additional test was selected after the first two-source trial failed. Lock before reading CETL capacity labels, features or their distributions. New cohort, different measurement, same capacity question. Wu et al. provide 4,000 retired IFR32135 LFP cells, 15.5 Ah nameplate, 3-s samples, charge/rest followed by a full reference discharge. Use the previous published Salinas 70%-of-nameplate screen as a specified use case (10.85 Ah inclusive). It is an imported capacity specification, not a claim about a CETL customer's order or battery safety. The workload decision is whether to buy the full capacity discharge after charging. Use only charge-side fields as predictors. Discharge fields only for reference-label verification and retrospective workload. Analyze after charging; both channel options have incurred the same charging cost. A retains starting charging voltage alone; B retains starting voltage plus the charge trace.

Split the original record sequence into contiguous blocks of 20 before outcomes. Sort blocks by SHA256('CETL-TII-01|'+zero-based block index), then assign first 40% of blocks for training, next 25% for calibration, remainder for test. No random search or test refitting. Pack IDs/field sites are not reported; a block is an ordering device, not a verified physical pack. Detect exact duplicate charge traces across splits, quarantine all members of duplicate sets. Incomplete/nonphysical traces are withheld; publish counts. Do not remove difficult cases for poor prediction. If a grade is absent or either upper error bound fails, retain result.

Frozen training algorithm for A and B separately: predict capacity ratio with sklearn ExtraTreesRegressor (200 trees, min_samples_leaf=8, max_features=1.0, random_state=43, one worker). Features for A: first charging voltage. For B: A, number of charge samples, final and range of charge throughput, voltage and current at fixed fractions 0, .1, .25, .5, .75, .9, 1 of the finished charge, elapsed time and charged capacity at thresholds 3300,3350,3400,3450,3500,3550,3600 mV, and voltage/current means, standard deviations and extrema. An unreached threshold has -1 in its elapsed time and charge fields. Duration and fractions are deployable at charge completion. No imputed discharge features or inferred future signal. Scores order cells, they do not define the operating verdict.

Calibration: deterministic three-way threshold (monotone in score). For each grade sort calibration scores. For unsafe-to-pass and qualified-to-fail separately allow the largest count k with one-sided 97.5% exact binomial upper bound <=5%; choose strict threshold at the corresponding (k+1)-th extreme order statistic. Strict comparison handles ties conservatively. The order statistic defines a one-sided tolerance limit under exchangeability. If the sample cannot support any such order statistic, disable that direction. If thresholds cross, split at their midpoint and refer on exact ties. Freeze thresholds. Report error protection independently on test. Fit two channel rules on identical splits and publish the generic source, feature definitions, thresholds and version pins.

Primary success: B's two grade-conditional test error upper bounds <=5% with one-sided 97.5% Clopper–Pearson bounds on distinct held-out cells (requires independent target cells within grade), and strictly higher minimum empirical decisiveness than A. For a confirmed advantage also require paired exact one-sided tests for greater decisiveness in BOTH reference classes at .025 each, or a simultaneous strict maximin gap; report whether A also satisfies the side budgets. This is a direct evaluation of frozen score-restricted rules, not an unrestricted channel optimality certificate. Show transferability limitation from undisclosed pack IDs. Sensitivity: report errors and decisions by held-out blocks and a paired whole-block resampling interval (seed 43, 10,000 draws) for change in minimum class decision rate and saved discharge hours. Throughput: calculate measured gross additional discharge-channel time attached to cells receiving a decision under B vs A, using each trace's sampled elapsed discharge time, (count-1)*3s. Charge trace is routinely acquired in this use case, so report break-even extra data-handling burden in channel-equivalent minutes per assessed cell. Report wrong decisions separately; hours are potential, not realized production throughput. No imposed plant-wide d0.

Secondary deterministic measurement-design bound: because A is a continuous scalar in principle, an upper bound applies only to a registered finite quantizer. For A use a targeted predeclared four-bin quantizer with cutpoints at training quartiles of initial voltage. Estimate its two class-conditional state distributions on test with a common simultaneous 95% Clopper–Pearson box intersected with the simplex. Report the robust upper value at bilateral 5% for arbitrary randomized one-reading A-bin lookups using admissible distributions (a common-law witness certifies exactly 10%). Compare with a simultaneous lower value for the frozen B rule if coverage is combined: allocate .025 to the coarse region, .025 to all four rich-rule rates (two errors, two decisiveness rates). B qualifies only if the simultaneous side limits <=5%; otherwise mark the formal bound inconclusive. Interpret a joint result as a gap between coarse robust design and the rich feasible rule under the stated uncertainty construction, not universal inferiority of every continuous-voltage rule.
