# v25 numerical manuscript sources and evidence

The main manuscript, supplement, experimental inputs and published result tables are in this directory. The NASA step table is available directly at `evidence/NASA_chain_v2/data/nasa_steps.csv.gz`.

From the repository root use `python reproduce.py verify` for the distribution and paper checks, `python reproduce.py nasa` for a clean three-layer rebuild, and `python reproduce.py raw --help` for capacity replay. The [root README](../README.md) includes installation instructions for certlim 0.2.1, the matching source distribution and the historical workspace. The complete typesetting assets and submission PDFs are in the companion v25 paper package.
