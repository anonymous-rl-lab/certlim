# 冻结协议 — NASA PCoE 随机使用外部门 v01

**数据**:NASA PCoE *Randomized Battery Usage Data Set*,Zenodo `10.5281/zenodo.15277374`,CC-BY-4.0。
**冻结**:本文件与 `config/registered.json` 的 SHA-256 在任何 Δ / 𝒟 计算之前写入 `results/freeze.json`。

## 0. 为什么选这个数据集(与前三个的结构差别)

动作 A 由**显式给定的概率分布随机抽取**,分布写在数据集文档中并被独立实测验证。因此:
P(H=1 | Z, do(A)) **可识别**,Ψ 是真值而不是代理;混杂臂可以按已知潜变量重采样**构造并验证**;
同一 θ 下 n 自由可变。前三个数据集(Jones / Severson / Zhu)结构上都不提供这三条。

## 1. 纳入与排除(冻结)

1. 七个子集全部纳入,28 个电芯(RW1–RW28),仅用随机游走**放电**步。
2. **共同支撑**:动作归并到 A ∈ {1,2,3,4} A(整数档)。均匀臂实测 5 A 档占比 0.0%,故 5 A 被排除以保证跨臂重叠。
3. **完全重叠区**:仅保留起始电压 V0 ≤ 4.0 V 的步。V0 > 4.0 V 时 A=3,4 无样本。
4. 状态 Z = V0 的四箱:`(0,3.55]`, `(3.55,3.7]`, `(3.7,3.85]`, `(3.85,4.0]`。
5. θ = (电芯, 老化阶段),要求该单元 ≥150 步。阶段由参考放电循环切分。

## 2. 危害、策略与安全目标(冻结)

- **危害 H=1**:该随机游走放电步终止于 3.2 V 保护截止(实现为 `Vend ≤ 3.25`)。
  这是**保护介入事件**,不是事故;选它是因为它高频(均匀臂 47.9%)、强动作依赖、随老化上升。
  容量衰减阈值作为敏感性备选(见 §7)。
- **策略 π**:与状态无关的动作分布(数据集本身的策略就是这种形式),在 {1,2,3,4} 上重整化:
  `uniform = (.25,.25,.25,.25)`,`skew_high = (.05,.20,.15,.60)`,`skew_low = (.25,.60,.10,.05)`。
- **参考状态分布** p_ref:均匀臂上 Z 的池化边缘分布,冻结。
- **策略风险**:Ψ(θ,π) = Σ_z p_ref(z) Σ_a π(a) · P̂(H=1 | Z=z, A=a, θ),其中 P̂ 仅在该格 ≥5 步时估计。
- **等级**:Θ_S = {Ψ ≤ 0.15},Θ_U = {Ψ ≥ 0.35},其余为缓冲带。
  阈值取自全部 1539 个 (θ,π) 组合的 Ψ 三分位 (0.078, 0.364) 的就近整数,**在计算任何 Δ 或 𝒟 之前设定**。
  敏感性:(0.20,0.40) 与 (0.25,0.45)。

## 3. 证据通道与离散化(冻结)

单次观测的证据符号 `e = 2·1{A ≥ 3} + H`,字母表 K=4。
模型 (θ,π) 的证据分布 P_{θ,π}(e) 由与 Ψ 相同的公式在 (Z,A) 上边缘化得到。
n 个 iid 观测的实验用**多项计数**充分统计量表示(计数向量对 iid 多项分布充分,凸包 TV 在充分统计下不变)。

## 4. 三条主线与判据

### L1 — 主定理的直接检验(定理 1(1))
对每个 n,用 LP **精确求解**最大决定性覆盖率
𝒟(n) = sup_Γ inf_{θ∈Θ_S∪Θ_U} P_θ(Γ ≠ Alert),约束 sup_{Θ_U} P(Certify) ≤ α、sup_{Θ_S} P(Reject) ≤ β,α=β=0.05。
同时用凸包 LP 求 Δ_E(n)。
- **G1**:对所有 n,`𝒟(n) ≤ min{1, α+β+Δ_E(n)}`。任一 n 违反即证伪主定理。
- **G2**:在 Δ_E(n)=0 处,`𝒟(n) = α+β`(界可达,不只是上界)。

### L2 — 门函数二分与块设计(定理 1(2)(4))
- **G3**:Δ_E(n) 关于 n 单调不减。
- **G4**:n⋆ = min{n : Δ_E(n) > 0} 有限;且 γ⋆(n) = Δ_E(n)/2(Sion 对偶恒等式)在所有 n 上成立,残差 ≤ 1e-8。
- 报告 Hoeffding 块设计 N(n) = n·⌈L/(2γ⋆(n)²)⌉ 的最优块长,以及精确最优 N(由 L1 的 LP 给出),量化保守性分层。

### L3 — 碰撞的构造与验证(命题 1 的实证对应物)
从随机臂出发,按一个**被视为不可观测**的潜变量 U(该 θ 单元内步的温度中位数二分)对步做重采样,
使 A 与 U 相依,构造混杂臂。要求:
- **G5**:构造出的一对 (θ_S, θ_U) 在混杂臂上的证据分布 TV ≤ 1e-6(碰撞成立),
  而它们由随机臂算得的真值 Ψ 分居 Θ_S 与 Θ_U 两侧(等级相反)。
  这是 Θ_sf 非空的**实证见证**,不是假设。
- **G6**:在该碰撞对上,𝒟 ≤ α+β;而把未混杂的随机臂作为附加通道后,Δ > 0 且 𝒟 恢复。

## 5. 零分布校准

所有 Δ 报告置换零分布(打乱 (θ,π) 的等级标签,保持每类数量,B=500),给出 Δ̂、零均值、超出量与置换 p。

## 6. 重采样单位

**电芯**。同一电芯不同阶段的 θ 单元不独立;所有自助与置换以电芯为块。

## 7. 敏感性(必做)

1. 阈值 (0.20,0.40)、(0.25,0.45)。
2. 危害改用「该阶段容量衰减率 > 中位数」。
3. 证据字母表 K ∈ {2,4,8}。
4. 状态分箱边界 ±0.05 V。

## 8. 先行声明的局限

1. H 是**保护介入**而非事故。审稿人可能不接受它作为 safety hazard;论文须以"保护介入率"表述。
2. 每子集仅 4 芯;θ 数量(513)靠 (芯×阶段) 撑起,同芯单元相关,故重采样以电芯为块。
3. 均匀臂无 5 A 档,跨臂评估限于 {1,2,3,4}。
4. 步内条件 iid 由实测 lag-1 相关支持(条件于状态箱后中位 −0.020),但不是严格独立。
5. Ψ 的格估计要求每格 ≥5 步,格覆盖率中位 0.81;未覆盖格以 NaN 略过,可能引入轻微偏差。
