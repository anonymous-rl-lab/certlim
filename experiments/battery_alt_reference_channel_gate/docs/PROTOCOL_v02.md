# 冻结协议 v02 — Battery ALT 标准探针认证实验

本文件与 `config/registered_v02.json` 的 SHA-256 记录在 `results/freeze_v02.json`,
在任何 Δ / 𝒟 计算之前写入。v01 为什么被 G0 否掉、v02 与它的关系,见 `docs/ERRATA.md` A 节。

---

## 1. 这个实验问什么

论文的问题是 OTA 场景的:**用便宜、标准化的台架证据,能不能认证一个将在现场负载下运行的单元。**
Battery ALT 恰好自带这个结构:

- **危害发生在现场负载下。** 每个包按测试台指派的载荷等级(4.9–24 A)跑 regular mission,
  危害 H = 该 mission 内电芯表面温度 max > 70 °C。这是真实热事件,不是代理。
- **证据来自标准探针。** `mission_type = 0` 是贯穿全生命的**恒流参考放电**,
  实测 2.520 ± 0.001 A,26 个包 481 段全都一样。动作恒同,包间可比。

于是问题落成:**从 n 次标准参考放电,能不能把 Safe 包和 Unsafe 包分开;分不开的话,是暂时分不开还是永远分不开。**

## 2. 单元与等级(在任何 Δ / 𝒟 之前固定)

- θ = 电池包,要求参考放电段 ≥ **15**。26 个包中 16 个入选。
- h(θ) = P(max T > 70 °C | regular mission),按 h 的三分位分级:
  S = 最低三分之一,U = 最高三分之一,A = 中间。
- 实际切点 h = 0.1509 / 0.4786,得 **S 6 个、A 5 个、U 5 个**。
  逐包的 h 与等级记录在 `results/freeze_v02.json`。

注意等级与组别不独立:3 个 `second life` 包全部落入 S。置换零假设**以组为块**,
因此保留这个关联,任何存活下来的 Δ 都不能用组别单独解释。

## 3. 证据通道(冻结)

单次参考放电给出三个特征,按**入选包参考放电的合并中位数**二值化(切点记录在 freeze 文件):

| 特征 | 含义 | 切点 |
|---|---|---|
| `dur` | 放电时长,容量代理 | 2880.794 s |
| `rise = T_max − T_0` | 温升,热阻代理 | 9.015 °C |
| `V_med` | 负载电压中位 | 7.0795 V |

- K = 8:`4·b(dur) + 2·b(rise) + b(V_med)`
- K = 4:去掉 `V_med` 位(`sym8 // 2`)
- K = 2:再去掉 `rise` 位(`sym8 // 4`)

三者是**同一分划的严格嵌套粗化**。这一点是刻意的:Zhu 包里各菜单独立量化过一次,
非嵌套的量化器造出过一个假的数据处理违例(Δ_g > Δ_X),那次教训写在 Zhu 包的 ERRATA 里。

每个包的 pmf 用 **add-δ 平滑,δ = 0.5** (Krichevsky–Trofimov)。K = 8 时每包中位有 4 个空格,
不平滑会让支撑集人为不相交。δ ∈ {0, 0.5, 1} 进敏感性。

主分辨率 **K = 4**;K 敏感性 {2, 4, 8}。

## 4. 计算对象

- 第 n 次抽样的实验用**多项计数充分统计量**精确枚举(C(n+K−1, K−1) 个状态),不做蒙特卡洛。
- Δ_E(n) = 安全侧凸包与危险侧凸包的全变差,由线性规划精确求解 —— 不是逐对散度的最小值。
- 𝒟_{α,β}(E,n) = 在 sup_U P(Certify) ≤ α、sup_S P(Reject) ≤ β 下,
  随机化三态规则的 inf_θ P(Γ ≠ Alert) 的上确界,也由线性规划精确求解。
- α = β = 0.05;n 网格 1,2,3,4,5,6,8,10,12,15,20(K = 8 只到 10,因为 n = 20 有 888 030 个状态)。

## 5. 门(判据在冻结时写定)

| 门 | 判据 |
|---|---|
| **G0** 可行性 | 每个 θ 中样本 ≥5 的动作档位数的中位 ≥ 3 —— **v01 的轴,已 FAIL,见 ERRATA** |
| **G1** 上界 | 每个 n、每个 K 上 𝒟 ≤ min{1, α+β+Δ} |
| **G2** 可达 | 对抗构造的跨等级碰撞上 Δ = 0 且 𝒟 = α+β,误差 ≤ 1e−8 |
| **G3** 单调 | Δ_E(n) 与 𝒟(E,n) 关于 n **单调不减**(ERRATA E1 更正了方向) |
| **G4** 门函数 / n⋆ / Sion | G_E(n) = 1{Δ = 0} 单调不增;n⋆ = inf{n : G_E(n) = 0};\|γ⋆(n) − Δ(n)/2\| ≤ 1e−6 |
| **G6** 数据处理 | 嵌套链上 Δ_{K4} ≤ Δ_{K8}、Δ_{K2} ≤ Δ_{K4};且 Δ_{(X,g(X))} = Δ_X |
| **G9** 留出包 | 按包号奇偶把 16 个包切成两半,G1 在每一半上独立成立 |

**永久障碍**按定理 1(3) 的正确陈述检验:G_E(n) = 1 对所有 n **当且仅当**存在
**逐对**精确碰撞 P_{θS} = P_{θU}。因此同时报告最小逐对 TV 与凸包 TV(ERRATA E4)。

零假设:等级标签在组内置换 500 次,统计量为注册的 Δ_E(1);
因观测 Δ_E(1) 恰为 0(取值范围下端),另附报 Δ_E(20) 与 n⋆,不替换注册统计量。

敏感性:危害阈值 {60, 70, 80} °C × 最少参考放电 {10, 15, 20} × δ {0, 0.5, 1},共 27 组设定。
