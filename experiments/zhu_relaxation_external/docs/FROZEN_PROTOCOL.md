# 冻结协议 — Zhu 2022 电压弛豫外部门 v01

**冻结时刻**:本文件与 `config/registered.json` 的 SHA-256 在任何模型拟合之前计算并记录于 `results/freeze.json`。
**数据**:Zhu et al., *Data-driven capacity estimation of commercial lithium-ion batteries from voltage relaxation*, Nature Communications 13, 2261 (2022). DOI `10.1038/s41467-022-29837-w`. 数据 Zenodo `10.5281/zenodo.6405084`, CC-BY-4.0.

## 0. 本协议不主张什么

- 弛豫电压是**非派生测量通道**(non-derived measurement channel),不是 SCM 意义上满足条件独立性或完备性的因果代理。本实验不声称识别隐藏共同原因。
- 域内 Δ 是**可认证性**指标,不是漂移距离。跨域主张只通过 ρ 与 M 表述。
- 阈值 (100,150) 周期是在观察 EOL 分布之后选定的(唯一能使源域双侧的配置),**属于选择性阈值**,故同时报告 (100,200)、(110,160)、(100,140) 敏感性。主分析仍冻结在 (100,150)。

## 1. 数据纳入与排除(冻结)

1. 仅用 Dataset_1 (NCA) 与 Dataset_2 (NCM)。**排除 Dataset_3 (NCM+NCA)**:其充电后静置协议为 3570 s / 120 点 / 30 s,与 NCA/NCM 的 1680 s / 15 点 / 120 s 不同,化学与测量协议不可分离。
2. 排除充电后静置时长 < 1600 s 的电芯(截断记录)。
3. 中断周期剔除:逐周期放电容量 `cap_c`,若 `cap_c < 0.5 × median(cap, 居中窗口 11)` 则剔除该周期。
4. EOL@p:剔除后序列上,首个满足 `cap ≤ p·c0` 且**连续 3 个有效周期**均满足的周期;`c0 = median(前 5 个有效周期)`。主分析 p=0.90。
5. 敏感性:窗口 ∈ {7,11,15} × 因子 ∈ {0.4,0.5,0.6} × k ∈ {2,3,4};并报 EOL@95 一致性。
6. 单位是**电芯**。所有重采样、置换、自助均以电芯为单位。

## 2. 安全目标与等级(冻结)

- 危害事件 H=1 :EOL@90 ≤ 100 周期。
- 域 = (化学, 温度, 充电倍率)。域即待部署策略 π。
- 策略风险 Ψ(θ) = P(H=1 | 该域),以域内经验频率估计。
- Θ_S = {Ψ ≤ 0.10};Θ_U = {Ψ ≥ 0.30};其余为缓冲带 Θ_A。缓冲带不受两侧错误约束。
- 单元格级三决策(A 线用):Reject 若 EOL ≤ 100;Certify 若 EOL ≥ 150;否则缓冲。

## 3. 证据菜单(全部仅用前 10 个周期)

| 菜单 | 内容 | 角色 |
|---|---|---|
| `summary` | 8 维循环摘要:放电容量均值/斜率/末值/标准差、充电容量均值、库仑效率、周期时长均值/斜率 | 基线通道 X |
| `g_summary` | X 的**确定性粗化**:每维按冻结的全局三分位量化为 3 档 | g(X),有损 |
| `summary_derived` | X ∪ g(X) ∪ 固定确定性变换(平方项、两两乘积、逐列秩) | (X, g(X)),无新 σ-代数 |
| `relax` | 第 5、10 周期充电后弛豫曲线在公共 15 点栅格上的取值 + ΔV + V0 | 非派生通道 W |
| `summary_relax` | X ∪ W | 并集 |
| `relax_permuted` | W 在域内块置换(200 次,冻结种子) | 负对照 |

**所有变换均为固定的确定性函数,不含任何在数据上拟合的步骤**(不用 PCA、不用任何学习到的映射),以保证 θ-无关性严格成立。

## 4. 离散化与 Δ 的计算(冻结)

- 由于每域仅 2–27 芯,插件 TV 在 K=16 / n=17 下零假设期望已达 0.498。故量化字母表冻结为 **K=4**,并使用**严格嵌套**的量化器族 K ∈ {2,4,8} 报告单调性。
- 量化:菜单内各特征先做逐列秩变换,取第一主方向的等频 K 分箱(方向由冻结的固定权重向量给出,非拟合)。
- Δ_E:θ = 域;P_θ = 该域量化证据的经验分布;K_S = co{P_θ : θ∈Θ_S},K_U = co{P_θ : θ∈Θ_U};Δ = LP 求 inf TV。
- **零分布校准(强制)**:对每个 Δ,做 B=500 次域标签置换(保持每类域数不变),报告 Δ̂、零分布均值、Δ̂−E[零]、单侧置换 p。任何未经零校准的 Δ 不得进入结论。

## 5. B 线 — 数据处理推论(主线)

三条**配对**预言(同一批电芯、同一 n、同一量化分辨率,故偏差在配对差中抵消):

- **P1** `Δ_{g_summary} ≤ Δ_{summary}`(数据处理不等式,允许严格小于)
- **P2** `Δ_{summary_derived} = Δ_{summary}`(未增加 σ-代数,应精确相等;容差 = 零分布标准差)
- **P3** `Δ_{summary_relax} ≥ Δ_{summary}`(非派生通道可以严格增大)

判据落在 **LP 最优三决策前沿**上,不落在任何模型的实测 coverage 上。任何模型性能单独报告,**不作为数据处理定理的证伪对象**。

**证伪条件**:P1 被违反(Δ_{g} 显著大于 Δ_{X});或 P2 被违反(配对差显著非零)。

## 6. A 线 — 四点迁移案例(降级为案例,非曲线)

唯一能标定双侧规则的源域:`NCA_T45_C0.5`(9 unsafe / 7 buffer / 11 safe @ 100/150)。四个单侧目标:

| 目标 | n | 位移 | 可测侧 |
|---|---|---|---|
| NCA_T25_C0.5 | 17 | 温度 | unsafe |
| NCA_T25_C1.0 | 8 | 温度+倍率 | unsafe |
| NCA_T25_C0.25 | 5 | 温度+倍率 | safe |
| NCM_T45_C0.5 | 25 | 化学 | safe |

- 源域内:留一交叉拟合 + split-conformal(α=β=0.10,分位数 `ceil((n_cal+1)(1-α))/n_cal`,`higher`)。
- 有向漂移:ρ^S = sup_{P′∈K_{S,d′}} inf_{P∈K_{S,d}} TV;ρ^U 同理(目标→源方向)。
- **两条单向不等式预言**:
  - **Q1** `Δ_{d′} ≥ Δ_d − ρ^S − ρ^U =: M`(三角不等式引理)
  - **Q2** 目标侧错误 ≤ `α+ρ^U`(unsafe 侧)/ `β+ρ^S`(safe 侧)
- 每个目标只测一侧;决断率与侧错误成对报告(全 Alert 的规则侧错误为 0 但决断率为 0)。

## 7. 门控(冻结判据)

- **G0 完整性**:纳入排除按 §1 复现;电芯不重复;源域两侧各 ≥5 芯。
- **G1 (P1)**:`Δ_{g} − Δ_{X} ≤ 零分布 95 分位` → PASS。
- **G2 (P2)**:`|Δ_{derived} − Δ_{X}| ≤ 零分布标准差` → PASS。
- **G3 (P3)**:`Δ_{X+W} − Δ_{X}` 的置换 p < 0.05 → 非派生通道严格增益;否则报告为"未检出增益"(非失败)。
- **G4 (Q1)**:四个目标全部满足 `Δ_{d′} ≥ M` → PASS。
- **G5 (Q2)**:四个目标全部满足侧错误界 → PASS。

失败的门如实报告,**不重调阈值、不改菜单**。

## 8. 已知局限(先行声明)

1. η²=0.886:域身份解释 log10(EOL) 的 88.6% 方差,安全等级近乎域身份的确定函数。任何能读出协议的通道都会"预测对"等级。本实验因此不能把 B 线的增益解释为因果信息增益,只能解释为**证据集合上的分离度变化**。
2. 每域 2–27 芯,TV 估计噪声底见 §4;能分辨的差异量级约 ±0.15。
3. A 线四个目标各只有一侧可测,不构成双侧迁移保证。
4. 阈值为选择性(见 §0)。
