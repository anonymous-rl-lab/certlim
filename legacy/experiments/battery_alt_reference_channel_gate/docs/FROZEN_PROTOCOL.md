# 冻结协议 — NASA Battery ALT 外部门 + RW 留出臂验证 v01

**冻结**:本文件与 `config/registered.json` 的 SHA-256 在任何 Δ / 𝒟 计算之前写入 `results/freeze.json`。

## A 部分 — NASA Battery ALT(新数据集)

**数据**:*An accelerated Life Testing Dataset for Lithium-Ion Batteries with Constant and Variable Loading
Conditions*, Fricke, Nascimento, Viana (UCF/PML + NASA PCoE), 2023。
`https://data.nasa.gov/docs/legacy/battery_alt_dataset.zip`,MIT 许可。26 个电池包(每包 2 节 18650)。

### A.0 为什么加这个数据集

1. 主定理此前只由 NASA RW 一个实验承担。这是**另一实验室、另一批电芯、另一套协议**的独立复现底座。
2. `recommissioned` 组的包在**生命中途被指派了不同的载荷等级**(实测切换幅度中位 4.74 A,
   对照组 `regular` 为 0.50 A)。策略切换是真实发生的,不是重加权出来的。
3. `mission_type = 0` 是贯穿全生命的**恒流 2.5 A 参考放电**(实测电流 IQR 宽度为零),
   提供一个**动作恒同**的第二通道。

### A.1 纳入与排除(冻结)

1. 三组全部纳入:`regular_alt_batteries`(15)、`recommissioned_batteries`(8)、`second_life_batteries`(3)。
2. 只用 `mode = -1`(放电)行。mission 块 = 连续放电段(时间间断 > 60 s 或 `mission_type` 变化即断开),块内 ≥5 个采样点。
3. **弃用电压类危害**:`voltage_load` 的最小值在 100% 的 mission 上为 −0.03 V,是负载板断开的伪影。
4. θ = (电池包, 生命阶段),阶段 = 该包 `time` 的四分位;要求该单元 ≥30 个 regular mission。
5. 单位是**电池包**。所有置换、自助以包为块。

### A.2 危害、动作与策略(冻结)

- **危害 H = 1**:该 mission 块内 `temperature_battery` 的最大值 > **70 °C**。
  这是电芯表面温度的真实热安全事件。敏感性:60 °C 与 80 °C。
- **动作 A**:mission 的中位放电电流,分 5 档 `(0,8] (8,11] (11,14] (14,17] (17,∞)` A。
  动作由测试台外生指派,故 P(H | do(A)) 可识别。
- **策略 π**:5 档上的分布。冻结三个:
  `uniform = (.2,.2,.2,.2,.2)`,`heavy = (.05,.10,.15,.35,.35)`,`light = (.35,.35,.15,.10,.05)`。
- **Ψ(θ,π) = Σ_a π(a)·P̂(H=1 | θ, A=a)**,格估计要求该 (θ,a) 格 ≥5 个 mission。
- **等级**:Θ_S = {Ψ ≤ τ_S},Θ_U = {Ψ ≥ τ_U}。τ 取全部 (θ,π) 组合 Ψ 的三分位就近值,
  **在计算任何 Δ 或 𝒟 之前设定**,并在 `results/thresholds.json` 记录其来源。

### A.3 证据通道(冻结)

- **主通道** `mission`:符号 `e = 2·1{A 档 ≥ 4} + H`,字母表 K=4(与 RW 包保持可比)。
- **参考通道** `reference`:参考放电块(动作恒为 2.5 A)的摘要,离散化同法。
- **派生对照** `reference_derived`:参考通道摘要的确定性变换,列数与另一真实通道**逐列匹配**。
- n 个 iid 观测用多项计数充分统计量表示。

### A.4 门控

- **G1** 𝒟(n) ≤ min(1, α+β+Δ_E(n)),α=β=0.05,n ∈ {1,2,3,4,5,6,8,10,12,15,20}。任一 n 违反即证伪主定理。
- **G2** 若网格上出现 Δ=0,则该处 𝒟 = α+β。
- **G3** Δ_E(n) 关于 n 单调不减。
- **G4** n⋆ 有限;Sion 恒等式 γ⋆(n) = Δ_E(n)/2,残差 ≤ 1e-7。
- **G5(策略切换)** 对 `recommissioned` 包:仅用**切换前**的证据认证**切换后**的载荷 regime,
  与切换后**直接观测到的** Ψ 比对。`regular` 包(不切换)为匹配对照。
  判据:切换组的认证误差显著大于对照组(以包为块的置换检验,p < 0.05),
  或如实报告未检出差异。
- **G6(推论 1)** 在参考通道上:`Δ_{reference_derived} − Δ_{reference}` 不得超过维度匹配的冗余底。

### A.5 零分布校准

所有 Δ 报告置换零分布(打乱等级标签、以包为块,B=500),给出 Δ̂、零均值、超出量与置换 p。

## B 部分 — NASA RW 留出臂验证(既有数据集,新分析)

RW 数据集含三条**真实执行过**的策略臂:`uniform`、`skew_high`、`skew_low`。
既有分析的 Ψ 由同臂内重加权得到;本部分做真正的留出验证:

- 仅用 `uniform` 臂的日志,按已知倾向性估计目标策略 `skew_high` 与 `skew_low` 的 Ψ;
- 与**真的跑过该策略**的那条臂上直接测得的 Ψ 比对。
- **G7** 估计 Ψ 与留出臂实测 Ψ 的绝对偏差中位数 ≤ 0.05,且两者 Spearman ρ ≥ 0.7;
  否则如实报告 Ψ 识别链在跨臂时的偏差幅度。
- 单位为电芯;置信区间以电芯为块自助(B=1000)。

## C 先行声明的局限

1. **倾向性是估计的,不是已知的。** ALT 数据集未给出动作分配的闭式概率表(RW 给了)。
   指派仍外生(测试台设定),故识别成立,但倾向性由数据估计。
   主结论因此同时在**参考通道**(动作恒为 2.5 A,无需倾向性)上报告。
2. 26 个包;θ = (包 × 阶段) 撑到约 100 个单元,同包单元不独立,故重采样以包为块。
3. mission 块内不是 iid;θ 定义在阶段粒度上以近似满足假设 1,并报告实测的块间自相关。
4. 载荷 regime 在包之间差异很大,某些 (θ, 动作档) 格可能无样本;格覆盖率如实报告。
5. `second_life` 组仅 3 包,不单独作结论,并入总体。
