# v04 生死门实验：科学契约

## 1. 被检验的理论对象

本包只对应 `Theory_Chapter_Safety_Certification_Limits_v04.md`。认证目标是策略风险

\[
\Psi(\theta,\pi)=P_\theta(H=1\mid do(A=\pi)),
\]

而不是旧 v51 包中的观测—干预失真量。旧证据是 \((A,H)\)，新增注册通道是二元代理 \(W\)。

## 2. 生死门与失败含义

| Gate | 理论主张 | 失败意味着什么 |
|---|---|---|
| G1 | 成对 SCM 的旧证据精确碰撞 | 永久不可认证见证的代数或实现错误 |
| G2 | 部署动作改变时安全/危险角色翻转 | 认证对象没有真正写成“模型—策略”对 |
| G3 | 旧证据派生特征不能破永久门 | 数据处理推论的实现错误 |
| G5 | 注册二元代理产生正 TV，且等于 \(\delta\) | 正面对照不能切断原碰撞 |
| G6 | \(\Delta(1)=0,\Delta(2)=1/8,\gamma(2)=1/16,n_\star=2\) | 有限块见证或 LP 错误 |
| G7–G8 | \(\Delta(n)\) 单调，原—对偶值相等 | 主定理的统一泛函闭环未被代码复现 |
| G9 | \(\Delta(N)\ge1-\alpha-\beta\) 首次发生在预注册位置 | 任意无 Alert 规则的必要样本门计算错误 |
| G10 | 最优 Hoeffding 块长可以严格大于 \(n_\star\) | 规定性采购结论未成立 |
| G11–G12 | 精确代理错误受理论界控制，模拟吻合精确尾概率 | 有限样本实现或随机验证错误 |

任何 Gate 失败均判该阶段失败；不得通过删点、改阈值或更换种子事后修饰。修复代码或理论后必须提升实验版本并完整重跑。

## 3. 预注册数值

- 有限类：安全侧 \(p\in\{1/4,3/4\}\)，危险侧 \(p=1/2\)。
- \(\alpha=\beta=0.05\)，无 Alert 必要距离为 0.9。
- 已冻结地标：\(n_\star=2\)，首个必要无 Alert 块长 47，Hoeffding 总样本最优块长 14，总样本上界 266。
- 数值容差：\(10^{-8}\)。
- smoke 完全确定性；small 使用配置中列出的 20 个种子，每条件每种子 2000 次二项模拟。
- Monte Carlo 只校验实现，真值采用精确二项尾概率。通过阈值为每个条件、每个错误方向均落在 `max(5 SE, 0.01)` 内。

## 4. 可证与不可证

本实验可验证注册有限模型类上的精确分布等式、LP 几何、对偶分离、样本下界必要条件及特定代理构造。它不能证明任意代理有效、不能验证代理的潜变量语义、不能保护缓冲带 \(\Theta_A\)，也不构成电池或工业现场的外部有效性证据。
